Prepared and explicitly approved October 27, 2026. Executed successfully: the calculator-only route and pinned image are live. Original routes/configuration and selected existing site behavior were preserved. The sequence below records the approved plan; the lesson issue and GitHub authentication were completed after deployment. See SPEC for current GitHub evidence.

## Result and existing setup

Launch a new calculator at https://calc.lwdgyasteri.com on the learner's existing
DigitalOcean droplet. DNS resolves to the same address as the main domain.
The SSH target and identity key remain private local settings, not tracked here.
Docker access works through sudo.

Traefik v3.7.14 uses its file provider, watching `/etc/traefik/dynamic`, mounted
from `/opt/lwdgy-security-lab/dynamic`. Existing routes serve the main domain
and `dev.lwdgyasteri.com`. The `websecure` entry point uses container port 8443,
published as host port 443. The existing `letsencrypt` resolver uses the HTTP
challenge through the `web` entry point. The proxy joins the existing
`lwdgy-security-lab_edge` network as well as the application networks.

The supplied launcher generates Docker routing labels, but this proxy has no
Docker provider. Therefore the adaptation adds one separate file-provider route.
It does not enable a Docker provider or mount the Docker socket into Traefik.

## Recovery if the trial fails

Preserve sanitized failure evidence. Remove only the new route file after
confirming its path and content match this trial. Stop/remove only the verified
lesson-owned calculator Compose project using its own saved manifest. Never use
the existing application stack's Compose file or remove its external networks.
Recheck the original sites. Leave shared certificate storage intact. If anything
unexpected was modified or ownership is unclear, stop and investigate instead
of broad cleanup. There is no required rollback exercise on a successful launch.
